# dopamint — Enterprise AI Cryptocurrency SaaS Platform 👑

An enterprise-grade AI cryptocurrency chat application and live telemetry dashboard with OKLCH theme architecture (Light & Dark modes), powered by React 19, Vite 8, Tailwind CSS v4, Framer Motion, and Zustand.

## 🎨 Theme System (OKLCH)
- **Light Theme**:
  - Canvas Background: `#f3f2e6` (`oklch(0.957 0.016 95)`)
  - Primary Accent: `#55604e` (`oklch(0.485 0.035 135)`)
  - Card Surfaces: `white` (`oklch(1 0 0)`)
  - Text Primary: `black` (`oklch(0.16 0.01 135)`)
- **Dark Theme**:
  - Canvas Background: `oklch(0.18 0.014 135)`
  - Card Surfaces: `oklch(0.23 0.018 135)`
  - Primary Accent: `oklch(0.74 0.065 135)`
  - Text Primary: `#f3f2e6` (`oklch(0.957 0.016 95)`)
